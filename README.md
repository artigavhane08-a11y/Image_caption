
# Image_caption



🖼️ Image Captioning Project

## 📌 Project Overview
This project generates meaningful captions for images using the BLIP (Bootstrapping Language Image Pretraining) model.  
It combines Computer Vision and Natural Language Processing to describe image content automatically.

## 🚀 Technologies Used
- Python
- Transformers (Hugging Face)
- Torch
- Pillow

## 📂 Project Structure
Image-Captioning-Project
│
├── image.jpg
├── image_caption.txt
└── README.md

## ▶️ How to Run the Project

1. Install required libraries:
pip install -r requirements.txt

2. Run the Python file:
python image_caption.py

## 🧠 Output
The model analyzes the image and generates a descriptive caption.

Example:
Generated Caption: A man riding a wave on surfboard.
